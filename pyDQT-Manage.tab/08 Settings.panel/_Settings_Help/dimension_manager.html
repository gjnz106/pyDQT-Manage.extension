Dimension types

Settings Toolset›Dimension Manager

What it does

Lists every Dimension Type with how many instances are placed, so an unused type (a purge candidate) or a heavily-used one is visible at a glance.

Every Dimension is view-specific (unlike Model Groups), so selecting a type and clicking Detail always shows exactly which view each of its instances lives in, instantly.

Stat cards

Total
dimension types found
Unused
types with zero placed instances - purge candidates

Workflow

  1. Search filters by name, style, font, creator or workset.
  2. Double-click Text Size / Text Font / Width Factor to edit in place; Enter commits it.
  3. Detail shows every instance of the selected type and which view it's in.
  4. Select in Model / Zoom To act on the ticked rows; Rename / Batch Rename / Delete Type edit the type itself.
  5. Batch Edit Font/Width... sets Text Font and/or Width Factor on every selected type at once, instead of one cell at a time.

Good to know

Editing a cell in the grid changes that dimension TYPE, so every dimension using it updates too - the same as Batch Edit Font/Width.
