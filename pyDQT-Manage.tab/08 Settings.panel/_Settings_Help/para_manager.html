Parameters

Settings Toolset›Parameter Manager

What it does

Shows one parameter's value across every type in a chosen category, so it can be reviewed and edited in bulk instead of type by type in Revit's own Type Properties dialog.

Workflow

  1. Pick a category, then a parameter, to see it across every type.
  2. Edit a value in the grid and click Apply to write it back.
  3. Export CSV / Import CSV round-trip parameter values in bulk, outside Revit.

Good to know

Export CSV first if the plan is a large bulk edit - it's easier to review and edit many values in a spreadsheet, then Import CSV to apply them all at once.
