What it does

A tabbed manager covering loadable families, system families (Walls, Floors, Ceilings, Roofs) and Model Groups in one place, with rename, delete, parameter editing and a health check.

Tabs

Families
view/manage all families (loadable, system, and groups - filterable by kind)
Type Manager
manage family types
Parameters
view/edit parameters
Health Check
analyze issues across families

Workflow

  1. Pick a tab, then filter by Loadable/System/Groups as needed.
  2. Rename and Delete act on the current tab's selection - available from the Families tab or Type Manager.
  3. All / Clear select or deselect every row in the current grid.

Good to know

Rename and Delete are only wired up for the Families tab and Type Manager - Parameters and Health Check are for viewing/analysis.
