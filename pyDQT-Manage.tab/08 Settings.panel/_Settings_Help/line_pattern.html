Line patterns

Settings Toolset›Line Pattern Manager

What it does

Lists every Line Pattern in the model, separating built-in System patterns from project-defined Custom ones, so custom patterns can be renamed, batch-renamed or deleted (system patterns are protected).

Filters

Search
matches by name
Category
narrows to System or Custom patterns

Workflow

  1. Select All / Clear All / Select Custom pick rows for you.
  2. Rename edits one selected line pattern; Batch Rename edits many at once.
  3. Delete removes the selected custom patterns.
  4. Refresh reloads from the current document.

Good to know

System line patterns (Solid, Dash, Dot, etc.) are protected from rename and delete - only Custom patterns defined in this project can be changed.
