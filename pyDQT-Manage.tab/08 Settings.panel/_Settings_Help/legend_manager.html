Legend views

Settings Toolset›Legend Manager

What it does

Lists every Legend view with which sheet(s) it's currently placed on - a Legend is the only Revit view type that can sit on more than one sheet at once - and manages that sheet placement in bulk.

Filters

Search
matches by name
Show
narrows to placed / not-placed legends

Workflow

  1. Search / filter by Show to find the legend(s) you care about - Placed On lists every sheet it's currently on.
  2. Place on Sheets... opens a checklist of every sheet: for one selected legend it's a full sync (check to add, uncheck to remove); for several legends at once it only adds new placements.
  3. Rename / Duplicate / Delete act on the selected row(s).
  4. Batch Rename... opens the same tabbed Prefix/Suffix, Find/Replace, Remove, Change Case and Numbering rename tool the other managers in this suite use, applied to every selected legend at once.

Good to know

Duplicating a legend does not copy its sheet placements - the copy starts unplaced, so use Place on Sheets... on it separately.
