Family Font Manager

by Dang Quoc Truong (DQT)

Batch font change

Settings Toolset›Family Font Manager

What it does

Batch-changes the Text Font (and optionally Width Factor) of every font-bearing type across many loaded families at once - Text Note Types, and Label types used by tags, title blocks and section heads.

It targets every type with a Text Font parameter, not just TextNoteType - a Label placed in a tag/title block/annotation family uses its own "Tag Label" system-family type, a different class, which a TextNoteType-only scan would silently miss.

Workflow

  1. Tick categories on the left (or use Annotation only / All / None).
  2. Scan Selected Categories to preview every font-bearing type that will be affected.
  3. Pick a Target Font (and optionally tick Also set Width Factor), and, after scanning, an Only replace current font filter to narrow the change.
  4. Apply Font Change opens, edits and reloads each family in the background.

Good to know

Save the model before running - a large batch reloads many families in sequence, so a fresh save is worth having to fall back on.
Revit's screen may flicker as each family briefly becomes the active document while it's edited - that's normal, not an error, and needs no interaction.
Every step is logged to %USERPROFILE%/DQT_FamilyFont.log, so a run that stops partway can be diagnosed from the last line written.
