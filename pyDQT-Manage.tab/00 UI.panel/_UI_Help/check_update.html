Check Update

by Dang Quoc Truong (DQT)

Version check

UI Toolset›Check Update

What it does

Click the button and it immediately tells you whether the installed pyDQT-Manage is up to date, by comparing the local git commit with the latest commit on GitHub - there's no window to open first.

What you'll see

Up to date
the installed commit matches the latest on GitHub
Update available
a newer commit exists on GitHub, with the installed vs. latest short SHA and how to update
Not a git install
the extension folder has no .git - it wasn't installed via Git, so there's nothing to compare
Could not reach GitHub
a network problem prevented the check

How to update

  1. pyRevit ribbon › Update, then Reload, or
  2. run git pull in the extension folder, then Reload.

Good to know

This only works for a Git install. To enable one-click updates on a non-git install, reinstall pyDQT-Manage through pyRevit › Extension Manager using the Git URL: https://github.com/gjnz106/pyDQT-Manage.extension.git
