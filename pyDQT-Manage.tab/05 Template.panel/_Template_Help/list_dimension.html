Dimensions

Template Toolset›List Dimension

What it does

Draws one sample dimension for every Linear Dimension Type in the project, each rendered in its own type with a label, so every dimension style can be compared at a glance.

Workflow

  1. Pick a Text Style for the labels, and set Row Spacing, Dimension Span and Label Gap (all in mm) in the dialog that opens.
  2. Pick a point on the active view - the list is built downward from there, one row per type.
  3. A summary reports how many types were placed, and lists any that were skipped.

Why some types get skipped

Only Linear-style Dimension Types can be previewed this way - the sample is built from two reference tick-lines plus a straight dimension line, which is exactly what a Linear dimension is. Angular, Radial, Diameter, Spot Elevation, Spot Coordinate and Spot Slope types each need fundamentally different reference geometry.

Rather than guess at that geometry, the tool asks Revit itself: it builds the sample, then tries to re-type it to the target style. If Revit refuses, that type is named in the summary as skipped instead of being faked with the wrong geometry.
