Template Toolset›List Project Symbols

What it does

Places project annotation symbols - tags, heads, marks and similar point-placed annotation families - on a Legend view, grouped and labelled as Category > Family > Type, so the full annotation set can be reviewed at once.

Requires the active view to be a Legend.

Workflow

  1. Pick a point on the legend - categories are listed top to bottom, then family, then type, each level indented and labelled.
  2. Category and family headers are bold; each type is placed as an instance with its name labelled next to it.

Settings (Shift+Click the ribbon button)

Choose which annotation categories to include - by default a standard set of tag/symbol categories is used.
