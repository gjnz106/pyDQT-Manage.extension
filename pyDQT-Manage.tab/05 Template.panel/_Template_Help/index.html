What this panel is for

Builds a visual catalogue of the types already defined in a project - dimension styles, text styles, wall types, symbols, detail items, filled regions, line styles - by placing one labelled sample of each on the active view. Point it at a Legend view (or, for Walls, a Floor Plan) and it does the placing and labelling for you.

None of these tools has its own window - each is a quick point-and-run action, so there is no in-app "?" button to open this page from. Bookmark it instead, or come back to this index when you need it.

Shared behaviour

Pick a point
Every tool asks you to click a start point on the active view, then lays its list out downward from there.
Nothing found
If a project has no types of the relevant kind, the tool says so and stops instead of placing an empty list.
Shift+Click
List Walls and List Project Symbols keep their settings in a persistent config - Shift+Click the ribbon button to open it and change them before running.
A quick dialog first
List Dimension, List Detail Items, List Filled Regions and List Line Styles ask for their settings (text style, spacing, size) in a small dialog every time you run them.
