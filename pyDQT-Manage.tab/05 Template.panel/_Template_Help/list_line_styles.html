List Line Styles

by Dang Quoc Truong (DQT)

Detailing

Template Toolset›List Line Styles

What it does

Draws a short detail line for every Line Style under Object Styles > Lines, with a label, so all line styles can be reviewed at a glance.

Workflow

  1. Pick a Text Style and a Vertical Offset (mm) between lines in the dialog.
  2. Pick a point - one sample line per style is stacked downward, labelled with the style's name.
