Template Toolset›List Text Styles

What it does

Places one text note per Text Note Type in the project, each rendered in its own style, stacked in one column - the simplest way to see every text style side by side.

Workflow

  1. Pick a point on the active view - no settings dialog, it runs immediately.
  2. One text note is placed per style, each one labelled with its own type name, spaced automatically based on each style's text height so larger styles don't overlap the next line.
