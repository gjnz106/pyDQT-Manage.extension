Template Toolset›List Detail Items

What it does

Places every Detail Component type in the project, grouped by family with bold family headers and type labels, covering both kinds of detail component:

View-based
Placed as a point instance, like a symbol
Curve/line-based
Drawn along a short sample line of a fixed length

Workflow

  1. Pick a Text Style, Row Spacing and Line Length (for curve-based items) in the dialog.
  2. Pick a point - view-based families are listed first, then curve-based families, each with a bold family header.
