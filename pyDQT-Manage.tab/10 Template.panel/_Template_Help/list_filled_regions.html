Template Toolset›List Filled Regions

What it does

Draws a rectangle filled with each Filled Region type, with a label next to it, so every hatch/fill pattern in the project can be compared visually in one place.

Workflow

  1. Pick a Text Style and set the Box Width, Box Height and Offset between boxes (all in mm) in the dialog.
  2. Pick a point - one filled rectangle per type is stacked downward, each labelled with its type name.
