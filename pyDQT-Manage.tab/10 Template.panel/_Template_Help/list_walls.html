Walls

Template Toolset›List Walls

What it does

Lists every Basic Wall type (Curtain and Stacked walls are skipped - they don't have a single buildup to show). The view type decides how each one is shown:

Legend view
Each type is placed as a Legend Component, copied from an existing one already on the legend.
Floor Plan view
Each type is drawn as a real wall on the view's own level.

Workflow

  1. On a Legend view, place at least one Legend Component on it first (any category - it gets copied and re-typed per wall, and can be deleted afterwards). On a Floor Plan, nothing extra is needed.
  2. Pick a point - the list is built downward from there.
  3. Each wall type gets a label; if Include buildup is on, its full layer breakdown (thickness, function, material) is added under the name too.
