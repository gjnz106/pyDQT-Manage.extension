What this panel is for

The IFC-SG panel gets a Revit model ready for Singapore's IFC+SG (CORENET X) submission: create the parameters the requirements ask for, assign the correct IFC export class to every element, and check the result before the IFC file goes out.

The five tools are meant to be used roughly in this order - click any card below to open that tool's guide.

STEP 1

Parameter Loader

Create the required project parameters and bind them to the right categories, before anything else needs them.

 STEP 2

Auto Assign

Assign the IFC export class to every Family Type in one pass, by matching names against the Industry Mapping.

 STEP 3

Subtype Definer

Pick the exact subtype per Family Type from the Industry Mapping, for the cases Auto Assign could not resolve on its own.

 STEP 4

Manual Assign

Fix individual elements by hand - the handful Auto Assign and Subtype Definer could not map, or a value you want to override.

 STEP 5

IFC-SG Checker

Verify every required parameter actually exists and carries a value before the model goes out for submission.
