What it does

Reads the official IFC+SG Industry Mapping and lets you assign the exact IFC Entity and Predefined Type to each matching Revit type, component by component - this is where you pick which subtype (e.g. Blast Door vs a standard Door) rather than letting name-matching decide for you.

Use it after Auto Assign for the types that need a deliberate subtype choice, or whenever you want to browse one IFC-SG component and see every Family Type under it at a glance.

Stat cards

COMPONENTS
IFC-SG components loaded from the mapping Excel
ELEMENTS
Elements those components' categories hold in this model
UNRECOGNISED CATEGORIES
Category names from the Excel this tool could not resolve to a Revit category
SOURCE
The mapping Excel file that is currently loaded

Workflow

  1. Load Mapping Excel - a column-mapping dialog appears if the sheet's own headers do not match what the tool expects, so you can point it at the right columns once.
  2. Pick a component on the left; the grid on the right shows its Family/Type rows, how many instances each has, and a status: OK (entity + subtype set), No Sub (entity only) or Not Set (neither).
  3. Choose a subtype from the dropdown, then Apply to Selected (Ctrl+Click to select several rows first) or Apply to ALL.
  4. Auto-Assign fills in everything still missing in one pass, with a preview first - it never overwrites a value that is already set.

Options

Apply to Type
Write on the Family Type rather than each instance.
Also set IFC Entity
Write Export to IFC As as well as the subtype.
Set ObjectType for USERDEFINED
A * subtype writes USERDEFINED plus the name into IfcObjectType.

Good to know

The .xlsx is read directly - Microsoft Excel does not need to be installed on the machine, and the mapping file may stay open in Excel while you load it (an earlier version required closing it first).
Toposolid (Revit 2024+) and Topography (older Revit) are both handled automatically - you do not need to know which one your Revit version uses.
