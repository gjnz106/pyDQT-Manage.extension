What it does

Creates the project parameters the IFC+SG requirements ask for, and binds each one to the right categories - so a model starts out with every field the other tools (and the CORENET X checker) will look for.

Run this first, before Auto Assign, Subtype Definer or the IFC-SG Checker - they all read or write parameters this tool creates.

Stat cards

TOTAL
Parameters in the imported requirement list
EXISTING
Already present in this model
TO ADD
Missing - what Add Parameters will create
CATEGORIES
Distinct categories the list touches

Workflow

  1. Import the requirement list - from an Autodesk Model Checker XML export, or from an Excel mapping file.
  2. Filter / sort the list (All / New / Existing, sortable by name, group, category or status) and tick the parameters you want. Select New ticks everything not already in the model in one click.
  3. Add Parameters creates the ticked ones as Instance project parameters, bound to their categories.
  4. The Activity Log at the bottom records exactly what was created, so you have a record for the submission file.

Good to know

Missing category? A parameter with no category listed in the source file prompts you to pick which categories to bind it to, rather than silently being skipped.
Shift+Click works in the parameter list to tick a whole range at once, same as the other IFC-SG tools.
