What this panel is for

Model housekeeping - removing unused elements, unused family content, and elements you no longer need - with a preview and a scan step before anything is deleted.

These tools cover three different scopes: Smart Purge and Advanced Purge clean up unused content inside the current project, Purge Families cleans up a whole folder of .rfa files on disk, and Smart Delete removes specific elements you pick after checking what depends on them.

PROJECT

Smart Purge

Scan and remove unused elements, types and system content from the current project, grouped by category.

 POWER USER

Advanced Purge

The same idea with riskier operations added - unreferenced views, workset cleanup, deep model cleanup. Dry Run is on by default.

 ON DISK

Purge Families

Batch-purge every .rfa in a folder until Revit reports nothing purgeable left, with an optional bulk rename pass.

 TARGETED

Smart Delete

Pick specific elements and see what depends on them before you delete - flags anything that isn't safe to remove.
