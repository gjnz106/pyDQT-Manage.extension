What it does

Everything Smart Purge does, plus the categories that are riskier to automate: unreferenced views, workset cleanup, and a deeper model scan. A confirmation dialog and a Dry Run mode (on by default) both exist specifically because these operations can remove things Smart Purge deliberately leaves alone.

Opening the tool always shows a warning dialog first - read it. Use this tool only when Smart Purge's categories aren't enough for what you need to clean up.

Model Deep Cleanup

Dangerous Operations
The riskiest category - shown in red, off by default

Workflow

  1. Read the opening warning dialog and confirm you want to continue.
  2. Tick the groups to scan - Dangerous Operations is not pre-selected on purpose.
  3. Scan Selected or Scan All, then tick the categories you actually want to act on (Select All/None help).
  4. Leave Dry Run ticked to preview only - it's on by default. Only untick it once you're confident in the scan results.
  5. Delete system types is a separate, optional switch for system-level content - leave it off unless you specifically need it.
  6. Preview to see exactly what would be removed, then Execute (with Dry Run off) to actually purge. Close exits without changing anything.

Good to know

Dry Run is on by default for a reason. Run a scan with it on first, read the preview, and only turn it off once you're sure about what will be removed - these categories exist here rather than in Smart Purge because they need that extra look.
A backup before running this tool with Dry Run off costs a minute and undoes any surprise instantly - Smart Purge's categories almost never need one, this tool's riskier ones are worth it.
