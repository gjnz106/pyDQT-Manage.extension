Smart Delete Manager

by Dang Quoc Truong (DQT)

Targeted

Cleanup Toolset›Smart Delete

What it does

Analyzes what depends on a set of elements before you delete them, and flags anything that isn't safe to remove - instead of finding out after Revit's own delete-with-dependents warning.

Use this for deleting specific elements you've picked, as opposed to the Purge tools, which remove unused content you never explicitly selected.

Stat cards

SELECTED
Elements currently loaded into the list
DEPENDENCIES
Other elements/views that reference them
CRITICAL
Dependencies serious enough to reconsider deleting
HIGH RISK
Dependencies worth reviewing before deleting
SAFE
No dependencies found - clear to delete

Workflow

  1. + Pick Elements - select elements in the model (or start from your current Revit selection) to load them into the list.
  2. Narrow the list with Search, Category and Risk filters.
  3. View Details on a row to see exactly what depends on it.
  4. + Pick More adds to the list; Remove takes a row back out without touching the model.
  5. Zoom To / Select in Revit to locate an element; Export Excel saves the whole list.
  6. Delete Safe Only removes just the SAFE-risk elements; Delete All Selected removes everything currently in the list regardless of risk - use it deliberately, not by habit.

Good to know

A deletion here is a normal Revit transaction - Ctrl+Z undoes it like any other change, same as the confirmation message says after a delete finishes.
Delete All Selected does not re-check risk at the moment of deletion - review the Critical/High Risk rows first, or use Delete Safe Only.
