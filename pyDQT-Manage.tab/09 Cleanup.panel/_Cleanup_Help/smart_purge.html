Cleanup Toolset›Smart Purge

What it does

Scans the current project for unused content, grouped into simple categories, and removes only what you tick after you've reviewed it - nothing is deleted just by opening the tool.

Use this for routine project cleanup. If you also need to purge unreferenced views, worksets, or run a deeper model scan, use Advanced Purge instead.

Groups

Element Types
Unused family types and system types
Views & Sheets
Unused view-related content
Families & Types
Loaded families with no instances left
System Cleanup
Unused system content (line styles, fill patterns, etc.)

Workflow

  1. Tick the groups you want to cover, or leave all of them on.
  2. Scan Selected (only ticked groups) or Scan All - the category list below fills in with counts.
  3. Adjust the category checklist - Select Safe ticks only the categories flagged safe to remove, None clears every tick.
  4. Preview shows exactly what will be removed before anything happens.
  5. Purge removes the ticked items; Close exits without purging.

Good to know

Nothing is deleted by scanning - Scan only reports what exists. Deletion only happens when you press Purge, and Preview lets you double-check the list first.
If a category is not offered here at all, it usually means Advanced Purge covers it instead (riskier categories are kept separate on purpose).
