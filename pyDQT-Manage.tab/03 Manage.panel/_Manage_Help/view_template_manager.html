View Template Manager

by Dang Quoc Truong (DQT)

View templates

Manage Toolset›View Template Manager

What it does

Lists every View Template with an In Use / Unused count computed from how many views each template is applied to, so unused templates can be found and cleaned up.

Workflow

  1. Search filters by name; use the dropdown to narrow by view type.
  2. Rename / Batch Rename / Duplicate / Delete apply to the selected rows.
  3. Select one template and click Detail (or double-click its row) to see exactly which views use it - View Name, View Type, Scale and Sheet - and double-click a view there (or Open View) to switch to it.

Good to know

Deleting a template that's still applied to views resets those views to no template rather than failing - check the In Use count first if that matters for the project.
The Detail dialog's Sheet column covers both ordinary viewports and schedules placed on a sheet; a view shows "Not on Sheet" when it isn't placed anywhere yet.
The Usage / Usage % columns only ever showed a count - there was no way to see which views were actually using a template without searching the model by hand. Detail now lists them directly, with a one-click way to open any of them.
A view set to a Custom scale used to show the literal word "Custom" in the Scale column, on both the main grid and in Detail - not useful when the point is comparing scales across views. Both now show the view's real ratio (e.g. "1:96"), the same value Properties calls "Scale Value", falling back to the word "Custom" only if a view has no numeric scale to read.
A template's own Scale column on the main grid used to show a single number even when the template doesn't actually control View Scale - in that case each view using it can be a completely different scale, and the number shown was just whatever the template's own (often stale) Scale property happened to be. It now shows Varies whenever View Scale isn't one of the template's controlled parameters; open Detail to see each view's real scale.
