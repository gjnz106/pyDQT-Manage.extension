Material Manager

by Dang Quoc Truong (DQT)

Materials

Manage Toolset›Material Manager

What it does

Lists every Material in the model with whether it is in use and where, so unused materials can be found and cleaned up, and batch-renames materials in bulk.

Stat cards

Total
materials in the model
Visible
materials left after Search/Filter/Category
Selected
rows currently ticked
In Use
materials Revit's own dependency graph (Document.GetUnusedElements) says are genuinely in use
Unused
materials Revit itself has no use for right now - safe purge candidates

Columns

Status
In use / Unused, from Revit's own purge check - the same one the In Use / Unused cards, Select Unused and Delete go by, so it always agrees with the delete warning
Usage
how many things use the material: element types (in the type, in a wall / floor / roof / ceiling layer, or through a type parameter such as a family's Material), placed elements (their geometry - including instance parameters such as Structural Material - and faces painted with the Paint tool), and object styles (a category or subcategory, e.g. a family's subcategory material)
Usage %
its share of all those uses
Used By
the breakdown, e.g. 2 types, 15 elements, 1 object style

A material can still be In use with Usage 0 - something the tool cannot trace uses it, typically a family that is loaded but not placed. Used By then says so; purge that family first and the material becomes Unused.

Workflow

  1. Search / Filter by Usage / Filter by Category narrow the list.
  2. Rename renames one selected material.
  3. Batch Rename applies a Prefix/Suffix, Find/Replace, Remove, or Case change to every ticked row at once.
  4. Duplicate copies a material; Delete removes the ticked ones.

Good to know

Sort or filter by the Unused stat first if the goal is cleanup - it surfaces exactly the materials safe to remove without checking each one manually.
Usage read 0 for materials the delete warning called "in use". Usage only counted element types, through a test that misses most of them, while the warning goes by Revit's purge check, which sees every use. Usage now also counts wall/floor layers, type parameters, placed elements (geometry and paint) and object styles, the new Status column shows the purge check directly, and the delete warning lists where each material is used.
