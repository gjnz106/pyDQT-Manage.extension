CAD Import Manager

by Dang Quoc Truong (DQT)

CAD cleanup

Manage Toolset›CAD Import Manager

What it does

Lists every imported and linked CAD file (DWG/DXF/etc.) in the model with who created it, which workset and view it's in, and its level - so stray or duplicate CAD content is easy to find and remove.

Stat cards

Total
CAD imports + links found
Imports
files imported directly into the model
Links
files linked (not imported) into the model
Selected
rows currently ticked in the grid
Unused Types
CAD Import/Link Types with zero instances left - orphans safe to purge

Columns worth knowing

ID
the placed instance's own Element ID
Type ID
the CAD Type's Element ID, shared by every instance of that file - this is the ID ACC's Model Analytics reports, so paste it into Search to find that file's instances here
Type
Import (geometry embedded in the model) vs Link (external .dwg still on disk)

Filters

Search
matches name, creator, workset, view, ID or Type ID
Type
All / Import only / Link only

Workflow

  1. Search and/or filter by Type to narrow the grid.
  2. Select in Model or Zoom To to jump to the ticked CAD file(s) in Revit.
  3. Export CSV to save the current (filtered) list.
  4. Delete removes the ticked CAD import/link - any Type left with zero instances afterward is purged automatically in the same step.
  5. Purge Unused Types finds and deletes every CAD Type with zero instances left, including ones left over from before this feature existed; Close exits the tool.

Good to know

Double-click a row's ID to copy it; double-click elsewhere on the row to select + zoom to that file directly.
Delete is permanent for that model session beyond Ctrl+Z - double-check the selection (or use Zoom To first) before deleting CAD content other people may depend on.
A CAD import shows up in ACC's Model Analytics (Insight) but not here? This tool can only see what the current Revit session has actually loaded. A CAD import/link sitting on a workset you closed when opening the model is invisible to it - and to every other in-session tool - even though Insight still finds it, since that reads the whole .rvt file server-side regardless of any user's open-workset choice. An orange banner appears above the stat cards naming exactly which worksets are closed whenever that's the case; reopen the model with all worksets open to see the complete list here too.
Deleted every instance, but ACC still reports the CAD import as present? ACC's Model Analytics reports CAD imports at the Type level (one entry per unique CAD file), not per instance. Revit never auto-deletes a Type just because its instance count reaches zero - it lingers as an unused Type, and since that's exactly what ACC is reporting on, it keeps showing up there indefinitely. Run Purge Unused Types here, then Sync/upload a new version and wait for ACC to reprocess it.
Unused Types reads 0 but ACC still lists the file? Then the file is genuinely still in the model. Match ACC's Element ID against the Type ID column (or paste it into Search) to see its remaining instances - delete those and the Type is purged along with them.
Every CAD file used to be labelled Link, leaving the Imports card permanently at 0 even in models with genuine imports. The Import/Link check started from ImportInstance.IsLinked, which is missing on some Revit 2026 builds, and then treated any non-null external file reference as proof of a link. It now asks IsExternalFileReference() on the CAD type first - the documented, version-stable answer - and only falls back to the older checks, requiring a reference that actually resolves to a path before calling something a link.
