Text Note Type Manager

by Dang Quoc Truong (DQT)

Text note types

Manage Toolset›Text Note Type Manager

What it does

Lists every Text Note Type with an In Use / Unused count computed from actual TextNote instances in the model, so unused types are easy to find and clean up.

Workflow

  1. Search filters types by name; tick rows (or Select All) to act on them.
  2. Double-click Text Size / Font / Width Factor to edit one type in place, or tick Bold / Italic directly in the grid.
  3. Batch Edit... sets Text Size, Font, Bold, Italic and/or Width Factor on every ticked type at once, instead of one cell at a time.
  4. Rename / Batch Rename / Duplicate / Delete apply to the ticked rows.

Good to know

IN USE / UNUSED counts come from TextNote instances in the model, not from the type list alone - a type can look unused here even if it's referenced by a schedule or tag that doesn't place a TextNote.
Batch Edit... is new - tick several types, tick which of Text Size / Font / Bold / Italic / Width Factor to change and to what, and Apply sets all of them in one transaction. A type missing one of the ticked parameters is skipped for that field only, not treated as a failure.
