What it does

Lists every In-Place Family in the model with its geometry complexity and any naming/quality issues, so the ones worth converting to a real loadable family (or deleting) are easy to find.

Stat cards

Total
in-place families found
Selected
rows currently selected in the grid
Categories
distinct categories they use
Issues
rows flagged with a naming or complexity issue

Status colours

Green (OK)
within normal complexity
Orange (Warning)
getting complex
Red (Error)
very high face count

Thresholds for these colours are configurable in the tool's Settings.

Workflow

  1. Search / Filter / Category narrow the list.
  2. Zoom To, Select, Isolate act on the selected rows.
  3. Rename applies a naming pattern to the selected family.
  4. To Family converts the selected in-place family to a real loadable family; Delete removes it.
  5. CSV / Report export the visible list.

Good to know

Converting to a loadable family and deleting are both hard to fully undo across a session - use Isolate or Zoom To first to confirm which element you're targeting.
