Warnings

Inquiry Toolset›Warning Manager

What it does

Browses, filters and resolves Revit model warnings, with impact analysis before you delete anything.

Views

Grouped Warnings
warnings collapsed by type, with a count per group (the default view)
All Warnings
a flat, paginated list of every individual warning

Quick actions toolbar

Refresh
reload warnings from the current document
Load All Warnings
load the full warning list (skips the initial page limit)
Select All
select every element referenced by the visible warnings
Batch Operations
mark all resolved, select/isolate all elements, export the filtered list to Excel, or clear resolved warnings
View History
see a log of actions already taken this session, with an option to clear it
Export Excel / Export PDF
save the current (filtered) warning list to a report file (PDF export needs the reportlab package)
Close
close the Warning Manager window

Filtering

Quick filter chips narrow the list to a warning category with one click; Clear Filters resets them. Use the search box (Ctrl+F) to find warnings by text.

Duplicate / identical instance warnings

Opening a duplicate-instance warning shows every affected element with an impact rating so you can see what else references an element before deleting it:

NO impact
safe to delete - nothing else depends on it
LOW impact
a small number of dependents - review before deleting
HIGH impact
significant dependents - deleting is likely to break something else

Keyboard shortcuts

F5
Refresh
Ctrl+A
Select All
Ctrl+F
focus the search box

Good to know

Always check the impact rating before deleting a duplicate/identical instance - a HIGH impact element usually has other warnings or schedules relying on it.
