Inquiry Toolset›Workset Checker

What it does

Auto-generates one 3D QC view per workset - each generated view turns ON exactly one workset and turns OFF every other workset, so you can quickly review a discipline's content in isolation.

Stat cards

Total Worksets
user-created worksets found in the model
Selected
rows ticked in the grid, about to get a view generated
Existing Views
worksets that already have a matching QC view

Options

View name prefix
text prepended to each generated view's name (default QC-WS - )
Detail: Fine + Shaded w/ Edges
sets the generated view's detail level and visual style
Reuse view if name matches
if a view with the target name already exists, reuse it instead of creating a duplicate
Open first view when done
opens the first generated view once Generate Views finishes

Workflow

  1. Review the grid - Workset, Elements, and whether a matching view already Exists.
  2. Select All / Clear to choose which worksets get a view; Refresh reloads the list.
  3. Set the view name prefix and options on the left.
  4. Generate Views creates (or reuses) a 3D view per selected workset; Close exits without generating.

Good to know

Nothing is generated until you press Generate Views - selecting rows and changing options is safe to explore first.
With Reuse view if name matches on, running the tool again on the same worksets updates the existing views instead of piling up duplicates.
