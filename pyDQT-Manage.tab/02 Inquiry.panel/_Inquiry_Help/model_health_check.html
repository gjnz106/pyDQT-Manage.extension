by Dang Quoc Truong (DQT)

Inquiry Toolset›Model Health Check

What it does

Analyzes the model against 17 metrics - file size, warnings, CAD imports/links, in-place families, RVT links, worksets, views, sheets, groups, design options, reference planes, detail lines, filled regions, unplaced rooms, unpinned links, duplicate elements - and combines them into one weighted health score with a colour-coded heatmap.

Health scale

Each metric's row in the heatmap is coloured on this same scale, from best to worst:

Good
within a healthy range
Acceptable
fine, worth keeping an eye on
Warning
starting to add up
Concerning
worth addressing soon
Critical
likely already causing pain
Severe
well outside the healthy range

Workflow

  1. Re-Analyze re-runs all 17 metrics against the current model.
  2. Read the overall score and grade, then scan the heatmap for red/orange rows.
  3. Each row in the recommendations list has Select Elements to select the offending elements straight in Revit.
  4. Export Report saves the dashboard as a report file.

Good to know

This tool only reads the model - fixing a flagged metric (purging unused content, resolving warnings, converting in-place families, etc.) means switching to the matching tool elsewhere in pyDQT.
