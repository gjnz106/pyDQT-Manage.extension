Model Health Check

by Dang Quoc Truong (DQT)

Inquiry Toolset›Model Health Check

What it does

Analyzes the model against 12 metrics - file size, warnings, CAD imports/links, in-place families, RVT links, imported images, groups, design options, unplaced rooms, unpinned links, duplicate elements - and combines them into one weighted health score with a colour-coded heatmap.

Health scale

Each metric's row in the heatmap is coloured on this same scale, from best to worst:

Good
within a healthy range
Acceptable
fine, worth keeping an eye on
Warning
starting to add up
Concerning
worth addressing soon
Critical
likely already causing pain
Severe
well outside the healthy range

Workflow

  1. (Optional) Open the Settings tab first to adjust any metric's thresholds or weight to match your own standards, before running an analysis.
  2. Re-Analyze re-runs all 12 metrics against the current model.
  3. Read the overall score and grade, then scan the heatmap for red/orange rows.
  4. Each row in the recommendations list has Select Elements to select the offending elements straight in Revit.
  5. Export Report saves the dashboard as a report file.

Good to know

This tool only reads the model - fixing a flagged metric (purging unused content, resolving warnings, converting in-place families, etc.) means switching to the matching tool elsewhere in pyDQT.
Settings tab. Every metric's 5 threshold values (the upper bound of Good / Acceptable / Warning / Concerning / Critical - anything above Critical is Severe) and its weight (1-5, how much it counts toward the overall score) can be edited directly, right next to the Dashboard tab. Save & Apply writes the change to threshold_config.json next to this tool - so it survives closing Revit - and immediately re-scores the dashboard from the last analysis, no need to Re-Analyze again just because a threshold changed. Reset to Defaults restores every metric to the built-in values and deletes that file. A row with an invalid value (not a number, or out of ascending order) blocks the whole save rather than silently accepting the other 11.
