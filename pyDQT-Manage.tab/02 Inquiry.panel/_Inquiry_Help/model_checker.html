What it does

Runs a rule-based BIM compliance check against the model using a JSON checkset you can customise - covering Project Settings, Naming Conventions and Model Performance.

Project Settings
Revit version, Project Info, Survey/Base Point, Design Options, Worksets, Starting View, True North
Naming Conventions
Views, Sheets, Levels, Grids, Families
Model Performance
file size, warnings, CAD imports, in-place families, RVT links, groups, line patterns, rooms, duplicate marks

Stat cards

Total Rules
rules in the current checkset
Passed
rules that met the requirement
Failed
rules that did not
Info
informational findings, not failures
Skipped
rules that could not be evaluated

Workflow

  1. Pick a Checkset - New / Duplicate / Import / Export / Delete manage them.
  2. Tick the rules to run (Select All / None).
  3. Select a rule to see its details and, if it has any, edit its parameters - Save Parameters keeps the change.
  4. Run Check, then Export Excel for the report.

Good to know

Checksets are JSON, so a checkset built for one project's BEP can be exported and imported into another project rather than rebuilt by hand.
