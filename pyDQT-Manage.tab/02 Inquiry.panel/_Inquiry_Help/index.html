9 tools

What this panel is for

Read-only (or near read-only) model inspection - find, list, filter and report on what's already in the model, so problems can be spotted and fixed elsewhere.

Most of these tools list something (worksets, CAD links, images, group types, in-place families, materials, warnings) with search/filter, a Select in Model / Zoom To workflow, and a CSV/Excel/PDF export. Two go further: Model Health Check scores the model against 17 metrics, and Model Checker runs a customizable, rule-based compliance check.

VIEWS

Workset Checker

Auto-generate one 3D QC view per workset, isolating exactly that workset in each view.

 CAD

CAD Import Manager

List every imported/linked CAD file with creator, workset and view, then select, zoom to, export or delete them.

 RASTER

Image Manager

List every raster image placed in the model and flag any whose source file can no longer be found on disk.

 GROUPS

Group Manager

List every Model/Detail group type with instance counts, and drill into which views a type's instances live in.

 SCORE

Model Health Check

Scores the model against 17 metrics and shows a colour-coded dashboard with per-metric recommendations.

 FAMILIES

In-Place Model Manager

List every in-place family with geometry complexity and quality flags, to find conversion/deletion candidates.

 MATERIALS

Material Manager

List every material with its usage count, batch-rename them, and find unused ones worth purging.

 COMPLIANCE

Model Checker

Runs a rule-based BIM standards check (project settings, naming conventions, performance) against a customizable checkset.

 WARNINGS

Warning Manager

Browse, filter and resolve Revit warnings, with impact analysis before deleting anything.
