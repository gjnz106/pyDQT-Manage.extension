What this panel is for

Read-only model assessment - scoring and auditing the model as a whole, rather than changing anything in it.

These three report on model quality: Model Health Check scores it against 17 metrics, Model Checker runs a customizable rule-based compliance check, and In-Place Model Manager finds the in-place families worth converting or removing. Anything that lists and edits model content lives in the Managing panel instead.

SCORE

Model Health Check

Scores the model against 17 metrics and shows a colour-coded dashboard with per-metric recommendations.

 COMPLIANCE

Model Checker

Runs a rule-based BIM standards check (project settings, naming conventions, performance) against a customizable checkset.

 FAMILIES

In-Place Model Manager

List every in-place family with geometry complexity and quality flags, to find conversion/deletion candidates.
