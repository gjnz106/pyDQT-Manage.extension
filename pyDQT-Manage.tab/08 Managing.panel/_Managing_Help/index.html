Managing Toolset

by Dang Quoc Truong (DQT) · pyDQT-Manage

17 tools

What this panel is for

Managing what the model already contains - the elements placed in it and the named types and styles behind them. Each tool lists what's there with usage counts, lets you filter and select in bulk, and acts on the selection.

Most of these share the same shape: a stat-card row (Total / In Use / Unused / Selected), Search + Filter, a grid, and Rename / Batch Rename / Duplicate / Delete acting on the ticked rows. The first six work on placed content; the rest work on types and styles.

Placed content

WARNINGS

Warning Manager

Browse, filter and resolve Revit warnings, with impact analysis before deleting anything.

 MATERIALS

Material Manager

List every material with its usage count, batch-rename them, and find unused ones worth purging.

 VIEWS

Workset Checker

Auto-generate one 3D QC view per workset, isolating exactly that workset in each view.

 CAD

CAD Import Manager

List every imported/linked CAD file with creator, workset and view, then select, zoom to, export or delete them.

 RASTER

Image Manager

List every raster image placed in the model and flag any whose source file can no longer be found on disk.

 GROUPS

Group Manager

List every Model/Detail group type with instance counts, and drill into which views a type's instances live in.

Types and styles

FAMILIES

Family Manager

Tabbed manager for Families, Type Manager, Parameters and Health Check across loadable families, system families and groups.

 PARAMETERS

Parameter Manager

See one parameter's value across every type in a category, edit in bulk, and CSV round-trip the values.

 STYLES

Line Style Manager

List every Line Style (Lines subcategory) with weight, color and pattern, batch-rename or delete.

 PATTERNS

Line Pattern Manager

List every Line Pattern (System/Custom), rename or batch-rename, delete custom ones.

 TYPES

Text Note Type Manager

List every Text Note Type with In Use/Unused counts, rename, batch-rename, duplicate or delete.

 TYPES

Dimension Manager

List every Dimension Type with instance counts and per-view detail, with inline edit for Text Size/Font/Width Factor.

 WALLS

Wall Layer Manager

List every layer of every Basic wall type and batch-change layer Function, or batch-rename the wall types.

 PATTERNS

Fill Pattern Manager

List every Fill Pattern with its type and settings, rename, duplicate or delete them.

 BATCH

Family Font Manager

Batch-change the Text Font (and Width Factor) of every font-bearing type across many families at once.

 TEMPLATES

View Template Manager

List every View Template with how many views use it, rename, batch-rename, duplicate or delete.

 VIEWS

Legend Manager

List every Legend view with which sheet(s) it's placed on, and manage sheet placement in bulk.
