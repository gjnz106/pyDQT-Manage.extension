Image Manager

by Dang Quoc Truong (DQT)

Raster images

Managing Toolset›Image Manager

What it does

Lists every raster image instance placed in the model and checks its source file against disk right now, flagging any that can no longer be found.

Status meaning

Found (OK)
the source file exists at its recorded path
Missing File
Revit has a path but the file isn't there (moved, renamed, or on an unreachable drive)
No Path
Revit couldn't report a source path at all

Filters

Search
matches name, path, creator, workset or view
Status
narrows to Found or Missing

Workflow

  1. Search / filter by Status to find the images you care about.
  2. Select in Model or Zoom To the ticked row(s) - a missing image still shows a placeholder in its view, so both still work.
  3. Delete removes the ticked image instance(s); Undo restores them right after if needed.

Good to know

To fix a Missing image rather than delete it, use Revit's own Manage tab › Manage Images to browse to the file's new location.
