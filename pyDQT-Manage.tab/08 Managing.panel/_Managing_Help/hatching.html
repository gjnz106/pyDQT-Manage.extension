Fill Pattern Manager

by Dang Quoc Truong (DQT)

Fill patterns

Managing Toolset›Fill Pattern Manager

What it does

Lists every Fill Pattern in the model with its Type, its raw Pattern Settings, and its Grid count, so patterns can be renamed, duplicated or deleted directly from the grid.

Columns

Type
Drafting or Model pattern
Pattern Settings
the pattern's raw definition
Grids
number of hatch grid lines in the pattern

Stat cards

Total
fill patterns in the model
Selected
rows currently ticked

Workflow

  1. Search the list by name; tick rows (or Select All) to act on them.
  2. Rename / Batch Rename edit one or many ticked patterns' names.
  3. Duplicate copies a pattern; Delete removes the ticked ones.
  4. Refresh reloads from the current document.
