View templates

Managing Toolset›View Template Manager

What it does

Lists every View Template with an In Use / Unused count computed from how many views each template is applied to, so unused templates can be found and cleaned up.

Workflow

  1. Search filters by name; use the dropdown to narrow by view type.
  2. Rename / Batch Rename / Duplicate / Delete apply to the selected rows.

Good to know

Deleting a template that's still applied to views resets those views to no template rather than failing - check the In Use count first if that matters for the project.
