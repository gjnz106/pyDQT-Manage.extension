Managing Toolset›Group Manager

What it does

Lists every Model and Detail group type in the model with its instance count, creator and workset, and lets you drill into a type to see exactly which view(s) its instances live in.

Stat cards

Total Types
group types found (Model + Detail)
Model
Model group types
Detail
Detail group types
Selected
rows currently ticked in the grid

Filters

Search
matches name, creator or workset
Category
All / Model only / Detail only

Workflow

  1. Search / filter by Category to find the group type(s) you care about.
  2. Select in Model or Zoom To the ticked type's instances.
  3. Detail opens a breakdown of the selected type - which view(s) its instances are placed in, with its own Select in Model / Zoom To.
  4. Export CSV saves the current (filtered) list; Refresh reloads it; Close exits the tool.

Good to know

A type with an Instances count of 0 is loaded but unplaced - a purge candidate if it's not needed.
