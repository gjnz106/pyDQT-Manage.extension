Managing Toolset›Material Manager

What it does

Lists every Material in the model with how many elements use it, so unused materials can be found and cleaned up, and batch-renames materials in bulk.

Stat cards

Total
materials in the model
Visible
materials left after Search/Filter/Category
Selected
rows currently ticked
In Use
materials with at least one element using them
Unused
materials with none - purge candidates

Workflow

  1. Search / Filter by Usage / Filter by Category narrow the list.
  2. Rename renames one selected material.
  3. Batch Rename applies a Prefix/Suffix, Find/Replace, Remove, or Case change to every ticked row at once.
  4. Duplicate copies a material; Delete removes the ticked ones.

Good to know

Sort or filter by the Unused stat first if the goal is cleanup - it surfaces exactly the materials safe to remove without checking each one manually.
