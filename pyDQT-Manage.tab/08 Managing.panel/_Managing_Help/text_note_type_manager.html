Text note types

Managing Toolset›Text Note Type Manager

What it does

Lists every Text Note Type with an In Use / Unused count computed from actual TextNote instances in the model, so unused types are easy to find and clean up.

Workflow

  1. Search filters types by name; tick rows (or Select All) to act on them.
  2. Rename / Batch Rename / Duplicate / Delete apply to the ticked rows.

Good to know

IN USE / UNUSED counts come from TextNote instances in the model, not from the type list alone - a type can look unused here even if it's referenced by a schedule or tag that doesn't place a TextNote.
