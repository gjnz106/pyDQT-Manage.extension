Line Style Manager

by Dang Quoc Truong (DQT)

Line styles

Managing Toolset›Line Style Manager

What it does

Lists every Line Style - the subcategories of Revit's built-in Lines category - with its Weight, Color and Pattern, plus how many model lines use it, so they can be batch-renamed or deleted.

Columns

Line Style Name
the subcategory name
Weight
the line weight assigned to the style
Color
a colour swatch plus its RGB value
Pattern
the line pattern assigned to the style
Line Count / Usage %
how many detail/model lines use this style

Workflow

  1. Tick the line style(s) you want to change.
  2. Batch Rename... renames the ticked styles.
  3. Delete removes the ticked styles.

Good to know

Line Styles are Categories, not Elements - deleting one removes the subcategory itself, which affects every line already drawn with it.
